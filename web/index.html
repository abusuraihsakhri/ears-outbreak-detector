EARS Outbreak Detector

Explore unexpected increases in daily event counts using the C1, C2 and C3 Early Aberration Reporting System statistics. Analyze and export data locally in the browser.

1. Load daily counts

Use columns date,count with ISO dates (YYYY-MM-DD) and nonnegative integer counts. Maximum 2 MB.

Missing calendar days between observations are treated as zero, consistent with the Python CLI. Confirm that this assumption is appropriate for your surveillance data.

2. Configure analysis

Weekday filtering requires at least two matching observations. With a 7-day baseline, this option will not produce scores.

C1: prior baseline window; no gap.

C2: prior baseline window, separated by the selected gap.

C3: sum of max(0, C2(t−i) − 1) for i = 0, 1, 2.

Scores use sample standard deviation. Flat baselines with an increased count receive a finite score of 100. An alert is a statistical aberration, not proof of an outbreak.
